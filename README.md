## 🧐 O projekcie

Czy świat potrzebował kolejnego kalkulatora? **Absolutnie nie.**
Czy Bartek potrzebował projektu do portfolio, który wygląda na skomplikowany, a w rzeczywistości to kilka `if`ów? **Jak najbardziej.**

"Super Extra Bartkowy Kalkulator czy jakoś tak" to rewolucyjne narzędzie, które rzuca wyzwanie takim gigantom jak `calc.exe` czy ten kalkulator w Twoim telefonie, którego nigdy nie używasz. Został zaprojektowany z myślą o użytkownikach, którzy chcą dodać dwa do dwóch i oczekują, że wynik będzie wynosił cztery (w większości przypadków).

## ✨ Kluczowe Funkcjonalności (The "Extra" part)

Ten kalkulator jest napakowany technologią jutra, dostępną już dziś (chyba że serwer padnie):

* ➕ **Rewolucyjne Dodawanie**: Łączy dwie liczby w jedną większą. Magia.
* ➖ **Awangardowe Odejmowanie**: To jak dodawanie, ale na odwrót. Niesamowite.
* ✖️ **Eksperymentalne Mnożenie**: Dla tych, którzy lubią, gdy liczby szybko rosną.
* ➗ **Ryzykowne Dzielenie**: Zawiera zaawansowany system wykrywania dzielenia przez zero (program się crashuje, a przeglądarka zamraża – to tzw. "ficzer").
* 🎨 **Ultra-Minimalistyczny UI**: Zaprojektowany przez kogoś, kto przeczytał jeden artykuł o UX na Medium i uznał, że "mniej znaczy więcej" (bo nie umiał wycentrować `div`a).
* 🌙 **Dark Mode (Wkrótce™)**: Aktualnie "dark mode" polega na tym, że zamykasz oczy.

## 🛠️ Technologiczny Stack (Brzmi mądrze)

Projekt został zbudowany przy użyciu najnowocześniejszych technologii znalezionych na pierwszej stronie wyników Google:

* **HTML5**: Bo jakoś trzeba wyświetlić te przyciski.
* **CSS3**: Użyty desperacko, żeby całość nie wyglądała jak strona z 1998 roku (nie udało się).
* **JavaScript (ES6+)**: Mózg operacji. Zawiera więcej `console.log("Działa tutaj?")` niż faktycznego kodu.
* **Stack Overflow**: Prawdziwy autor 90% kodu.

## 🚀 Instalacja i Uruchomienie

Chcesz uruchomić to cudo na własnej maszynie? Odważnie.

1.  **Sklonuj repozytorium:**
    ```bash
    git clone [https://github.com/twoj-nick/super-extra-bartkowy-kalkulator.git](https://github.com/twoj-nick/super-extra-bartkowy-kalkulator.git)
    ```
2.  **Wejdź do folderu:**
    ```bash
    cd super-extra-bartkowy-kalkulator
    ```
3.  **Uruchomienie:**
    * Opcja dla hackerów: Postaw lokalny serwer (np. Live Server w VS Code).
    * Opcja dla Bartka: Kliknij dwukrotnie w plik `index.html` i módl się, żeby Chrome to uciągnął.
